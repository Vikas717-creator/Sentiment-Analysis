# 💬 Twitter Tweet Sentiment Analysis

A machine learning project for classifying the **sentiment of tweets** (Positive, Negative, Neutral) using **TF-IDF** and **Multinomial Naive Bayes**. Built to analyze public opinion and trends from social media data.

---

## 🌟 Features

- 🐦 Classifies tweet sentiments into **Positive, Negative, or Neutral**
- 📊 Trained using **TF-IDF vectorization** and **Naive Bayes classifier**
- 📈 Achieved **90% accuracy**, with **precision: 0.95** and **F1-score: 0.91**
- 📁 Includes preprocessing pipeline: lowercasing, stopword removal, and tokenization
- 💡 Easy to train on custom tweet datasets

---

## 🧠 Model Info

- ✅ **Algorithm:** Multinomial Naive Bayes  
- 📚 **Vectorizer:** TF-IDF (Term Frequency–Inverse Document Frequency)  
- 📄 **Dataset:** Publicly scraped or collected tweets with labeled sentiment  
- 🧪 **Accuracy:** ~90%  
- 📌 **Evaluation Metrics:** Accuracy, Precision, F1-Score
